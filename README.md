# Secure CI/CD Pipeline for Automated Application Deployment on AWS EKS

## Overview
Design and evaluation of a secure CI/CD pipeline for containerized application deployment on AWS EKS using Terraform, Jenkins, Docker, and Trivy.

## Objective
Compare manual Kubernetes deployment with an automated Jenkins pipeline on:
- Deployment lead time
- Failure and rework rate
- Security vulnerability blocking effectiveness
- Rollback time
- Infrastructure reproducibility

## Tools
AWS EKS, Terraform, Jenkins, Docker, Kubernetes, Trivy, Linux, Git
