# Project Description

This project designs and evaluates a secure CI/CD pipeline for containerized application deployment on AWS EKS. The infrastructure (VPC and EKS cluster) is provisioned with Terraform. Jenkins orchestrates build, test, Docker image creation, Trivy security scanning, and automated deployment to Kubernetes. The evaluation compares manual Kubernetes deployment (baseline) with the automated Jenkins pipeline across five measurable criteria: deployment lead time, failure and rework rate, security vulnerability blocking effectiveness, rollback time, and infrastructure reproducibility. Each deployment approach is run three times, and the averaged results are analyzed to derive practical recommendations for secure and reliable cloud-native delivery. The project builds directly on existing GitHub work in Terraform-based EKS provisioning and Jenkins pipeline automation.
